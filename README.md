# 🏠 House Price Prediction

## 📌 Project Description
This is a beginner-level Machine Learning project focused on predicting house prices using the California Housing Dataset. In this project, I explored the dataset, performed data cleaning and preprocessing, and applied Exploratory Data Analysis (EDA) to understand different features and their relationships.

I implemented Linear Regression and Random Forest Regression models to predict house prices and evaluated their performance using different regression metrics.

## 🎯 Project Objective
The main objective of this project is to understand how Machine Learning regression algorithms work and how different housing features influence house prices.

## 📊 Dataset
- **Dataset:** California Housing Dataset
- **Target Variable:** Median House Value
- **Task:** Regression
